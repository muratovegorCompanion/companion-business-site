# Копия сайта ICompanion

Готовая статическая версия сайта для размещения на любом хостинге. В папке есть:

- `index.html` — главная и маршруты через `?page=`;
- `styles.css`, `script.js` — оформление и интерактивность;
- `app.html` и `presentation-assets/` — локальная страница презентации приложения.

Для публикации содержимое этой папки нужно загрузить в корень нового домена. Сейчас фотографии и логотипы подключены с публичного CDN исходного Wix-сайта; при окончательном переносе их лучше сохранить в эту папку и заменить ссылки на локальные.

## B2B-главная, сентябрь 2026

`home.js` и `home.css` содержат новую главную. `npm run build` создаёт `dist/` со статически отрисованной главной, доступной без JavaScript. Остальные страницы сохраняют маршруты `?page=`. Манифест `.openai/hosting.json` относится к отдельной закрытой версии Sites, а не к действующему домену Companion.

Факты взяты из интервью владельца: около 97% продлений, около 15 000 застрахованных, 70–100 компаний (показано 70+). Длительность тендера и стандарты ответа относятся к ДМС. Расчётный объём премий, кейсы, клиентские логотипы и индивидуальный лимит Genesis не опубликованы на новой главной.

Форма «Домовитися про зустріч» работает с 7 сентября 2026: `data-meeting-endpoint` на `<html>` указывает на Cloudflare Worker `companion-meeting-form`, заявки приходят в Telegram-бота. Подробности и секреты — в `worker/ЧИТАЙ-МЕНЯ.md`.

## Домены и индексация

Основной домен — `icompanion.com.ua` (файл `CNAME`). Первые дни сайт жил на `sb-companion.com`; этот домен нужно переадресовать (301) на `icompanion.com.ua` у регистратора и отметить смену адреса в Search Console. Старые адреса и очевидные варианты названий страниц перенаправляет `404.html`; ссылки на главную ведут на `/`, а не на `index.html`.
