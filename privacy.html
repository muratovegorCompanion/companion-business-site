Захист інформації

Обробка та захист персональних даних

ТОВ «СТРАХОВЕ БЮРО «КОМПАНЬЙОН» обробляє персональні дані клієнтів та користувачів сервісу лише для цілей, пов’язаних із наданням посередницьких і супровідних послуг у страхуванні, виконанням договорів, звернень користувачів та вимог законодавства України.

Які дані можуть оброблятися

Залежно від послуги це можуть бути контактні та ідентифікаційні дані, відомості, необхідні для визначення страхового покриття та обслуговування договору, історія звернень, а також технічна інформація, необхідна для роботи цифрового сервісу.

Для чого використовуються дані

Для ідентифікації користувача, надання інформації про страхову програму, організації взаємодії зі страховою компанією та асистуючими службами, супроводу звернень, забезпечення роботи сервісу та виконання законодавчих обов’язків.

Передавання даних

Дані можуть передаватися страховим компаніям, асистуючим компаніям та іншим особам лише в обсязі, необхідному для надання відповідної послуги або виконання вимог законодавства. Дані не використовуються для цілей, несумісних із метою їх отримання.

Захист даних

Бюро застосовує організаційні та технічні заходи для обмеження несанкціонованого доступу, втрати, зміни або неправомірного розкриття персональних даних. Доступ до інформації надається лише тим особам і сервісам, яким він потрібен для виконання відповідних функцій.

Права користувача

Користувач має права щодо своїх персональних даних у межах, передбачених законодавством України, та може звернутися до бюро для отримання інформації про їх обробку, уточнення або реалізації інших передбачених законом прав.
