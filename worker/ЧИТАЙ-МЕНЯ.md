# Приёмник заявок с формы «Домовитися про зустріч»

Сайт лежит на GitHub Pages — там нет своего сервера, а токен бота нельзя
держать в коде страницы, иначе им сможет пользоваться кто угодно. Поэтому
заявку принимает маленький сервис на Cloudflare Workers: страница шлёт ему
данные, он проверяет их и пересылает в Telegram.

Токен вводите только вы и только в команду `wrangler secret put` — оттуда
он уходит прямо в Cloudflare. В переписку, в файлы и в git он попадать
не должен.

---

## 1. Бот и адрес, куда слать заявки

1. В Telegram откройте **@BotFather**, команда `/newbot`. Придумайте имя
   и адрес бота. В ответ придёт **токен** — строка вида `1234567890:AA...`.
   Это пароль, никому не показывайте.
2. Найдите своего бота по адресу и нажмите **Start** — без этого он не
   сможет вам написать.
3. Откройте **@userinfobot**, нажмите Start. Он пришлёт ваш **Id** —
   это чат, куда будут падать заявки.

Если заявки должны видеть несколько человек — заведите группу, добавьте
в неё бота, и Id возьмите у группы (тем же @userinfobot, отправив команду
внутри группы).

## 2. Выложить сервис

```bash
npx wrangler login
```

Откроется браузер, нужно разрешить доступ. Дальше:

```bash
cd ~/Desktop/companion-worker && npx wrangler deploy
```

В конце команда напечатает адрес вида
`https://companion-meeting-form.ваш-аккаунт.workers.dev`.
**Этот адрес пришлите мне** — он не секретный, я пропишу его на сайте.

Почему не `form.sb-companion.com`, как планировалось: свой адрес на домене
Cloudflare выдаёт, только если домен обслуживается им. У sb-companion.com
DNS сейчас на GoDaddy, так что берём бесплатный адрес на workers.dev —
сайт уже настроен его принимать.

## 3. Положить токен и Id

```bash
cd ~/Desktop/companion-worker && npx wrangler secret put TELEGRAM_BOT_TOKEN
```

Команда попросит значение — вставьте токен от BotFather и нажмите Enter.
На экране он не отображается и в файлы не пишется.

```bash
cd ~/Desktop/companion-worker && npx wrangler secret put TELEGRAM_CHAT_ID
```

Сюда — Id из шага 1.

## Что дальше делаю я

Пропишу адрес на сайте, кнопка формы разблокируется, отправлю тестовую
заявку и покажу, что она дошла.

## Если захотите дубль на почту

Сервис умеет присылать копию письмом через Resend. Нужен их ключ:

```bash
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put MAIL_TO          # egor_m@icompanion.com.ua
```

Без них ничего не ломается — заявки просто идут только в Telegram.

## Что сервис проверяет сам

- Принимает заявки только со `https://sb-companion.com`, с чужих сайтов — отказ.
- Скрытое поле-ловушка: если заполнено, это бот, заявка молча гасится.
- Имя, компания и контакт обязательны; телефон или email проверяются на вид.
- Длина полей ограничена, разметка в тексте экранируется.
- Без галочки согласия на обработку контактов заявка не принимается.
