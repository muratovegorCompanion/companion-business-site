# Приёмник заявок с формы «Домовитися про зустріч»

**Работает с 7 сентября 2026.** Адрес: `https://companion-meeting-form.icompanion.workers.dev`
Заявки падают в Telegram-бота `@companion_zayavky_bot`, в личный чат.

Сайт лежит на GitHub Pages — там нет своего сервера, а токен бота нельзя
держать в коде страницы. Поэтому заявку принимает сервис на Cloudflare
Workers: страница шлёт ему данные, он проверяет их и пересылает в Telegram.

## Если понадобится изменить код

```bash
cd ~/Desktop/companion-worker && npx wrangler deploy
```

## Если понадобится сменить токен или чат

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
```

Команда спрашивает значение отдельным приглашением, ввод не виден и в
историю команд не попадает. Никогда не подставляйте токен прямо в
командную строку: macOS выносит команду в заголовок окна Терминала.

## Дубль заявок на почту (необязательно)

```bash
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put MAIL_TO          # egor_m@icompanion.com.ua
```

Без них заявки просто идут только в Telegram.

## Что сервис проверяет сам

- Принимает заявки только с `https://icompanion.com.ua` и
  `https://sb-companion.com`, с чужих сайтов — отказ.
- Скрытое поле-ловушка: если заполнено, это бот — отвечает «принято»,
  но в Telegram ничего не шлёт.
- Имя, компания и контакт обязательны; телефон или email проверяются на вид.
- Без согласия на обработку контактов заявка не принимается.
- Длина полей ограничена, разметка в тексте экранируется.
